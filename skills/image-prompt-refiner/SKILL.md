---
name: Image Prompt Refiner
description: Expand a terse image-generation prompt with concrete visual detail
command: image-prompt
version: 1.0.0
requires:
  bins: []
  env: []
---
Take a short image prompt and expand it with concrete visual detail — composition, lighting, style reference — without changing the subject the user actually asked for.

Offer the refined prompt as a suggestion alongside the original, not a silent replacement, so the user can see exactly what changed before generating.
